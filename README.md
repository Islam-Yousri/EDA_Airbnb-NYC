   -   more info about app : https://www.airbnb.com/
   -   Workflow In ***Airbnb***  :
       -   🏠 A person owns an apartment in New York.
       -   👤 They list it on Airbnb.
       -   🧳 A traveler searches for a place to stay.
       -   💰 The traveler pays to stay there for a certain number of nights.
       -   ⭐ After the stay, the traveler can leave a review

***<font color="76C457">Features</font>*** 

1. **id** --> Unique identifier for each Airbnb listing.
2. **name** --> Name/title of the Airbnb listing.
3. **host_id** --> Unique identifier of the host who owns/manages the listing.
4. **host_name** --> Name of the host.
5. **neighbourhood_group** --> The larger NYC Place(Neighbourhood) where the listing is located: Manhattan, Brooklyn, Queens, Bronx, or Staten Island.
6. **neighbourhood** --> The specific neighborhood where the listing is located.
7. **latitude** --> Geographic latitude of the listing.
8. **longitude** --> Geographic longitude of the listing.
9. **room_type** --> Type of accommodation offered: Entire home/apt, Private room, or Shared room.
10. **minimum_nights** --> Minimum number of nights that a guest must book.
11. **number_of_reviews** --> Total number of reviews received by the listing.
12. **last_review** --> Date of the most recent review for the listing.
13. **reviews_per_month** --> Average number of reviews received per month.
14. **calculated_host_listings_count** --> Number of Airbnb listings associated with that host.
15. **availability_365** --> Number of days during the year that the listing is available for booking, from 0 to 365.

***<font color="76C457">Predicted Feature</font>*** ( $'target$ $Variable'$ ) 

**price** --> Price of the listing per night in USD.
